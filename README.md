# AI Software Engineer — Mini Devin

Mini Devin is a Python-based AI software engineering assistant that helps transform software requirements into working Python projects.

The application uses AI to understand a user's requirement, create a development plan, generate Python code, execute the generated project, detect errors, and iteratively improve the code.

## Project Objective

The objective of Mini Devin is to build an AI-assisted software engineering workflow that can automate common development tasks while keeping the system simple, understandable, and extensible.

## Key Features

* AI-powered software requirement analysis
* Automatic project planning
* Python code generation
* Automatic project file creation
* Python code execution
* Error detection and analysis
* AI-assisted debugging
* Iterative code improvement
* Task and execution history
* Project analytics and visualization
* Python-based web interface

## Installation

Clone the repository:

```bash
git clone https://github.com/Shrinidhi-02/ai-software-engineer-mini-devin.git
```

Move into the project directory:

```bash
cd ai-software-engineer-mini-devin
```

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## Environment Configuration

Create a `.env` file in the project root.

Add your AI API configuration:

```text
OPENAI_API_KEY=your_api_key_here
OPENAI_MODEL=your_model_name
```

Do not commit the `.env` file to GitHub.

## Running the Application

Start the Streamlit application:

```bash
streamlit run app.py
```

The application will open in your browser.

## Example Task

A user can enter:

```text
Create a Python calculator application with
addition, subtraction, multiplication and division.
```

Mini Devin analyzes the requirement and begins the software development workflow.

## Core Modules

### `app.py`

Provides the Streamlit web interface and handles user interaction.

### `ai_engine.py`

Handles communication between the Python application and the AI API.

### `planner.py`

Converts software requirements into structured development plans.

### `file_manager.py`

Creates and manages project files generated by the AI.

### `executor.py`

Executes generated Python programs and captures their output and errors.

### `agent.py`

Coordinates the complete AI software engineering workflow.

### `db.py`

Stores task history, execution results, and other application information using SQLite.

### `config.py`

Handles application configuration and environment variables.

### `utils.py`

Contains reusable utility functions used throughout the project.
