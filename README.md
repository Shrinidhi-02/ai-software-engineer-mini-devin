#  AI Software Engineer - Mini Devin

Mini Devin is a Python-based AI software engineering assistant.

The goal of this project is to build a small AI agent that can understand a software development task, create a development plan, generate Python code, execute the generated project, detect errors and attempt to fix them.

## Project Goal

The final application will follow this workflow:

User Task
↓
AI Planning
↓
Code Generation
↓
File Creation
↓
Code Execution
↓
Error Detection
↓
AI Debugging
↓
Re-execution
↓
Final Result
